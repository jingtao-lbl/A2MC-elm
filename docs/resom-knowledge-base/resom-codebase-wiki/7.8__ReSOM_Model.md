## Purpose and Scope

ReSOM (Reaction-network-based model of Soil Organic Matter and Microbes) is a sophisticated soil biogeochemistry module that explicitly represents microbial dynamics using a Dynamic Energy Budget (DEB) model framework. Unlike traditional first-order decay models, ReSOM simulates microbial growth, enzyme production, and substrate uptake as emergent properties of microbial physiology.

**Key distinguishing features:**
- **Explicit microbial biomass** with DEB-based growth dynamics
- **Enzyme-mediated decomposition** with Michaelis-Menten kinetics
- **ECA-based nutrient competition** among decomposers, nitrifiers, denitrifiers, and plants
- **Full C-N-P cycling** with optional C13/C14 isotope tracking
- **Adaptive ODE integration** for numerical stability

For the general BeTR framework and other BGC models, see [System Architecture](1.1__System_Architecture.md) and [Other BGC Models](7.6__Other_BGC_Models.md).

## Class Hierarchy and Architecture

### Inheritance Structure

```
jar_model_type (BeTR base for single-layer "jar" models)
    ↓
resom_bgc_type (single-layer ReSOM implementation)

bgc_reaction_type (BeTR base for multi-layer reactions)
    ↓
resom_bgc_reaction_type (multi-layer wrapper, contains array of resom_bgc_type)

plant_soilbgc_type (BeTR base for plant-soil coupling)
    ↓
resom_plant_soilbgc_type (ReSOM plant-soil coupling)

BiogeoCon_type (BeTR parameter base)
    ↓
resom_para_type (ReSOM parameters)
```

### Composition Structure

```
resom_bgc_type contains:
├── Decompresom_type       (decomposition kinetics & environmental scalars)
├── resomSom_type          (SOM pools, DEB model, decomposition dynamics)
├── resom_nitden_type      (nitrification, denitrification, N2O)
├── Compet_ECA_type        (ECA nutrient competition)
└── resom_bgc_index_type   (state variable indexing)
```

## Core Module Descriptions

### 1. Main BGC Type (`resomBGCType.F90`)

**Type:** `resom_bgc_type` (extends `jar_model_type`)

The main container for single-layer ReSOM biogeochemical calculations.

**Key Components:**
| Component | Type | Purpose |
|-----------|------|---------|
| `decompkf_eca` | Decompresom_type | Decomposition kinetics with environmental scalars |
| `nitden` | resom_nitden_type | Nitrification and denitrification |
| `sumsom` | resomSom_type | SOM pools and decomposition calculations |
| `competECA` | Compet_ECA_type | ECA nutrient competition |
| `resom_bgc_index` | resom_bgc_index_type | State variable indices |
| `ystates0`, `ystates1` | real arrays | Current and previous timestep state vectors |
| `k_decay` | real array | Decomposition rate constants |
| `cascade_matrix` | real 2D array | Decomposition pathway matrix |

**Key Public Methods:**
| Method | Purpose |
|--------|---------|
| `init()` | Initialize the BGC model with parameters |
| `runbgc()` | Execute BGC calculations for one timestep |
| `UpdateParas()` | Update parameters from configuration |
| `sumup_cnp_msflx()` | Calculate C/N/P mass fluxes |
| `getvarllen()`, `getvarlist()` | Variable metadata retrieval |

**Key Private Methods:**
| Method | Purpose |
|--------|---------|
| `calc_cascade_matrix()` | Build decomposition pathway matrix (C, N, P) |
| `init_states()` | Initialize state variables from forcing |
| `add_ext_input()` | Add external litter inputs |
| `bgc_integrate()` | ODE integration (adaptive Euler-Bashforth-Kunth) |
| `c14decay()` | Carbon-14 radioactive decay |
| `arenchyma_gas_transport()` | Plant aerenchyma gas exchange |

**Primary Variables (reactive):**

**Secondary Variables:**

**Diagnostic Variables:**

## Key Processes and Algorithms

### Decomposition Cascade

ReSOM uses a reaction network approach where organic matter flows through connected pools:

```
Litter Input
    ↓
┌─────────────────────────────────────────────────────┐
│  Lit1 (metabolic) → Mono → Mic ← Enz ← Poly        │
│  Lit2 (cellulose) ↗                ↓               │
│  Lit3 (lignin)   ↗             Residue → Poly      │
│                                     ↓               │
│  CWD/LWD/FWD ────────────────→ Mono               │
└─────────────────────────────────────────────────────┘
    ↓
  CO2 (heterotrophic respiration)
```

The `cascade_matrix` encodes these pathways for C, N, and P separately.

### Microbial DEB Model

Microbial growth follows Dynamic Energy Budget theory:

1. **Substrate uptake**: Monomer uptake by microbes (Michaelis-Menten kinetics)
2. **Reserve dynamics**: Energy storage and mobilization
3. **Growth allocation**: Reserve → Biomass + Maintenance
4. **Enzyme production**: Biomass → Extracellular enzymes
5. **Mortality**: Biomass → Residue

```
Monomer Uptake → Reserve (ec) → Growth (gB)
                            ↓
                    Enzyme Production (pE)
                            ↓
                    Maintenance Respiration (mr_mic)
```

### ECA Nutrient Competition

Equilibrium Chemistry Approximation solves nutrient partitioning:

**Competitors for N:**
- Microbial decomposers (NH4, NO3)
- Nitrifiers (NH4)
- Denitrifiers (NO3)
- Plants (NH4, NO3)

**Competitors for P:**
- Microbial decomposers
- Plants
- Mineral sorption (secondary P)

The ECA formulation:
```
Uptake_i = (Vmax_i * [S]) / (Km_i + [S] + Σ([S]/Km_j))
```
where competitors reduce effective substrate availability.

### ODE Integration

ReSOM uses an adaptive Euler-Bashforth-Kunth (EBK) solver:

1. **Initial step**: Forward Euler
2. **Subsequent steps**: 2nd-order Adams-Bashforth
3. **Error control**: Automatic step size adjustment
4. **Guard**: Prevent negative concentrations

```fortran
! Adaptive step control
if (error > tolerance) then
    dt = dt / 2
    retry
else if (error < tolerance/10) then
    dt = min(dt * 2, dt_max)
endif
```

## Integration with BeTR/ELM

### Connection Points

1. **Parameter Initialization**
   - `resom_para_type` loads from namelist/parameter files
   - Extends `BiogeoCon_type` for BeTR compatibility

2. **Forcing Data**
   - `JarBGC_forc_type` provides: temperature, water content, O2, CO2, pressure
   - Updated at forcing frequency (typically daily)

3. **State Variables**
   - Coupled to BeTR tracer framework via `resom_bgc_reaction_type`
   - Multi-layer vertical distribution

4. **Nutrient Uptake**
   - `resom_plant_soilbgc_type` handles plant-soil coupling
   - PFT-specific uptake parameters and root distribution

5. **Outputs**
   - Mass fluxes via `sumup_cnp_msflx()`
   - Diagnostic variables via `getvarllen()` and `getvarlist()`

### Model Selection

Select ReSOM by setting in the BeTR namelist:
```
reaction_method = 'resom'
```

## Usage Notes

### Spinup Considerations

ReSOM includes spinup acceleration via `apply_spinupf()` to accelerate slow SOM pool equilibration. Apply carefully as it can affect pool ratios.

### Parameter Sensitivity

Key parameters for calibration:
- `gmax_mic` - Controls microbial turnover
- `yld_mic` (CUE) - Carbon use efficiency, affects respiration
- `kaff_mono_mic` - Substrate affinity, affects competition
- `decay_enz` - Enzyme lifetime, affects decomposition
- `Q10` - Temperature sensitivity

### Numerical Stability

The adaptive ODE solver handles stiff systems, but extreme parameter combinations may require:
- Smaller `dt_max`
- Tighter tolerance
- More conservative initial conditions

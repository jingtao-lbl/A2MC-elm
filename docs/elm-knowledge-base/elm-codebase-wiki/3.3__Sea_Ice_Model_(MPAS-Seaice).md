## Purpose and Scope

This document describes MPAS-Seaice, the sea ice component of E3SM. MPAS-Seaice simulates the distribution, thickness, and motion of sea ice using unstructured Voronoi meshes from the MPAS framework. It integrates the Icepack column physics package for thermodynamic processes and provides multiple velocity solver options for ice dynamics.

For information about the MPAS framework and its core infrastructure (Registry.xml, streams, domain decomposition), see [MPAS Framework Deep Dive](#7) . For coupling with other E3SM components, see [Coupling Infrastructure](#4) . For ocean physics in MPAS-Ocean, see [Ocean Model (MPAS-Ocean)](#3.2) .

## Icepack Physics Package Integration

MPAS-Seaice integrates the Icepack column physics package developed by the CICE Consortium. Icepack handles thermodynamic processes including:

- Ice growth and melt
- Snow accumulation and metamorphosis
- Melt pond formation and evolution
- Biogeochemistry (optional)
- Radiative transfer through ice and snow

### Tracer System

MPAS-Seaice uses a sophisticated tracer system to track ice and snow properties across multiple thickness categories:

| Tracer Type | Variable Name | Description | 
| --- | --- | --- |
| Surface Temperature | index_surfaceTemperature | Surface temperature per category | 
| Ice Enthalpy | index_iceEnthalpy | Ice layer enthalpies | 
| Snow Enthalpy | index_snowEnthalpy | Snow layer enthalpies | 
| Ice Salinity | index_iceSalinity | Ice salinity profile | 
| Ice Age | index_iceAge | Age of ice | 
| First Year Ice | index_firstYearIceArea | First-year ice area fraction | 
| Pond Area | index_pondArea | Melt pond area fraction | 
| Pond Depth | index_pondDepth | Melt pond depth | 
| Aerosols | index_aerosols | Aerosol concentrations | 
| BGC Tracers | Various | Biogeochemistry tracers (optional) |

## Velocity Solvers

MPAS-Seaice provides multiple velocity solver options for ice dynamics:

![SVG image](3.3__Sea_Ice_Model_(MPAS-Seaice)__img-06.svg)

The EVP solver is the most commonly used option, employing explicit subcycling to solve the momentum equation with a viscous-plastic rheology. The variational solver uses an implicit formulation for improved stability at coarser resolutions or longer timesteps.

### Rheology and Stress Calculation

The ice rheology determines how ice deforms and flows under stress:

- **Yield curve**: Elliptical (default) or square
- **Plastic flow rule**: Normal flow or alternate formulations
- **Pressure formulation**: Affects ice strength calculation
- **Ridging scheme**: Energy-based redistribution or simple parameterizations

## Performance and Decomposition

MPAS-Seaice uses graph-based domain decomposition for parallel execution:

| Configuration | Variable | Description | 
| --- | --- | --- |
| Decomposition file | config_block_decomp_file_prefix | Path to graph partition file | 
| Number of blocks | config_number_of_blocks | 0 = one block per MPI task | 
| Halo exchange | config_use_halo_exch | Enable/disable halo communication | 
| Aggregate halos | config_aggregate_halo_exch | Bundle multiple fields | 
| Load balancing | config_load_balance_timers | Track timing for rebalancing | 


The decomposition file format is `{prefix}.{nprocs}` where `nprocs` is the number of MPI tasks. The buildnml script constructs the full path based on grid-specific settings.

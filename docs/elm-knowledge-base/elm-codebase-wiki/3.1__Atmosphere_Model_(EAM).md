## Purpose and Scope

This page documents the E3SM Atmosphere Model (EAM), including its build-time and runtime configuration system, major subsystems, and code organization. EAM is the prognostic atmosphere component in E3SM coupled simulations and can also run in standalone configurations with prescribed boundary conditions.

For detailed information on specific subsystems, see:

- [Dynamics Cores](#3.1.1)- HOMME spectral element and FV finite volume dynamics
- [Physics Parameterizations](#3.1.2)- turbulence, convection, microphysics, and radiation schemes
- [Chemistry and Aerosols](#3.1.3)- gas-phase chemistry and aerosol packages


For information about how EAM couples to other components, see [Coupling Infrastructure](#4) .

## EAM Overview

EAM (E3SM Atmosphere Model) is a global atmospheric general circulation model that evolved from the Community Atmosphere Model (CAM). The codebase retains many references to "cam" in directory names, file names, and code symbols for historical reasons. EAM predicts atmospheric state variables (temperature, winds, humidity, cloud water/ice, tracers) on a global grid using a dynamical core for fluid dynamics and physics parameterizations for subgrid processes.

Key Characteristics:

- **Component designation**`COMP_ATM=eam`: in CIME configuration
- **Source location**`components/eam/`:
- **Primary languages**: Fortran 90/95 with some C++ (for HOMME dynamics and SHOC physics)
- **Supported dynamics cores**: HOMME spectral element (se), FV finite volume (fv), Eulerian spectral (eul)
- **Vertical coordinate**: Hybrid sigma-pressure
- **Typical timesteps**: 900-7200 seconds depending on resolution

### Physics Parameterizations (see 3.1.2)

The physics package includes parameterizations for subgrid-scale processes:

- **Turbulence and shallow convection**: SHOC, CLUBB
- **Deep convection**: Zhang-McFarlane (ZM), UNICON
- **Microphysics**: MG2, P3
- **Radiation**: RRTMG, RRTMGP
- **Cloud macrophysics**: Diagnostic or prognostic schemes
- **Surface layer**: Monin-Obukhov similarity theory
- **Gravity wave drag**: Orographic and non-orographic


### Chemistry and Aerosols (see 3.1.3)

EAM includes comprehensive atmospheric chemistry:

- **Stratospheric chemistry**: Linoz (linearized ozone), WACCM chemistry
- **Tropospheric chemistry**: MOZART mechanisms
- **Aerosols**: Modal Aerosol Model (MAM4, MAM5)
- **Gas-phase chemistry**: UCI mechanisms, full chemistry packages

## Energy and Water Conservation

### Conservation Checking

The `check_energy` module tracks energy and water through the physics:

Conservation is tracked for:

- Total energy (internal + potential + kinetic + latent)
- Water (vapor + liquid + ice + precipitation)
- Dry air mass


Fixers are applied when:

- Numerical truncation errors accumulate
- Unbalanced source/sink terms exist
- Grid interpolation introduces errors

# `case_template/` — the reference case scripts this case is built from

**The worked, hand-authored scripts that materialise and submit a case.** For an ELM / ELM-FATES case these are CIME case scripts: one per phase of the spin-up chain (`ADSP` → `RGSP` → `TRANS`), plus the submitter that chains them with SLURM dependencies so the whole chain runs unattended.

They are **reference templates**, not the live launchers. Copy one, adapt it, and keep the adapted copy with the work it belongs to.

## Skills to use when working in this folder

| doing what | skill |
|---|---|
| **anything that materialises or submits a case** | **`phase0-design`** (a full ensemble) or **`offline-testing-workflow`** (a small variant experiment) |
| opening a round that needs a new staged file | `phase0-design` |
| restarting a case that timed out or failed | `restart-failed-jobs` |

## Where an adapted copy belongs

| the copy is… | it lives in |
|---|---|
| a **small offline experiment's** launcher (≤ ~10 variants, hand-authored) | `memory/phase_results/{stem}/` — repo-tracked, beside its param files, figures and captions |
| an **ensemble-scale** per-case script (thousands, auto-generated by `submit_phase0.py`) | scratch — regenerable, and it does not belong in the repo |

**Phase 5 copies its launcher into the phase folder — copy, never move.** The run directory is untracked scratch and gets cleaned, while the launcher is the only record of **which binary and which parameter file the run was bound to**. **Phase 0 is exempt**: its per-case scripts are config-generated and number in the thousands.

## Traps worth not rediscovering

- **Do not hand-code values into a copy.** Generate it with `tools/create_case.sh --write-script` so it sources the config chain, or a stale path silently outlives the config that was meant to own it.
- **Do not `module load python` before a CIME command.** It clobbers the A2MC environment and `create_newcase` dies; analysis-only scripts are exempt.
- **A restart is not a resubmit.** This project resumes via `finidat` + `RUN_STARTDATE` + `STOP_N`, never `CONTINUE_RUN` — cases run with `CONTINUE_RUN=FALSE`, so a plain resubmit silently re-runs from the original start date. Use `tools/restart_experiment_case.py`.

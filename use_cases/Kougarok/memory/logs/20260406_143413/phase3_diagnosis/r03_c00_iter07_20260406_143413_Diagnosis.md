## Protocol Recommendations

### A2MC_ADSP_NYEARS_AD_CARBON_ONLY (Priority: 1)
- **Current:** `30` → **Proposed:** `10`
- **Rationale:** The 30-year ADSP carbon-only phase builds substantial vegetation biomass (VEGC accumulation) before P cycling is activated. When P cycling begins, this latent biomass creates an instantaneous P debt that exceeds the available soil P pool (LABILEP=13.90 gP/m² at start of RGSP, depleted to 0.00 gP/m²). Reducing to 10 years allows P cycling to begin earlier when biomass is smaller, preventing the latent P debt from forming. This is the most mechanistically correct fix for the structural P starvation: the problem is not inadequate P supplementation (RGSP_SUPLPHOS=ALL is already set) but that the carbon-only phase creates an excessive biomass sink before P accounting begins. Reducing carbon-only years means biomass grows more slowly with P constraints active from the start, achieving a more realistic C:P balanced spinup. This fix addresses the root cause (Cause #1) rather than symptoms.
- **Requires re-spinup:** Yes

- **Requires re-spinup:** Yes

- PFT9 carbon starvation (86% of mortality) vs PFT7 hydraulic failure (76%): These represent different failure modes suggesting PFT9 and PFT7 are P-starved but with different allocation responses. PFT9's high vmax_p_9 (5e-05, upper bound) in Case #322 gives it 24.6% of P uptake despite having the smallest competitive advantage — but the PID controller responds to carbon starvation by reducing allocation, creating a spiral. When P supplementation is enabled, this L2FR configuration will create excessive root growth that over-expresses froot biomass.

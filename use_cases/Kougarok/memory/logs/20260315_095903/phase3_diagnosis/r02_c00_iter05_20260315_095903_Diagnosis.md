Cycle 4 skip-test confirmed l2fr_ini_9 vs PFT9_leaf r=-0.257 (strongest leaf predictor found for PFT9). With PFT9_leaf now at 26.6 vs target 124.7 (-78.7%), L2FR correction is essential.

- **Issue:** Case #322 has vmax_nh4_7=0.00025 (upper bound, 1000x above default 2.5e-9). ## Protocol Recommendations

### A2MC_RGSP_SUPLPHOS (Priority: 1)
- **Current:** `NONE` → **Proposed:** `ALL`
- **Rationale:** The fundamental structural problem is that SUPLPHOS=NONE during the regrowth spinup phase creates a 5-order-of-magnitude P supply/demand gap (0.857 g/m2/yr input vs 358,121 g/m2/yr demand). Enabling P supplementation during RGSP allows vegetation to reach realistic equilibrium biomass, then transition back to no-supplement during TRANS to test realistic P-limited steady state.

# ========================================================================
# Uncertainty Range Justification: ±20% of Observed Mean
# ========================================================================
#
# Rationale for using ±20% instead of standard deviation:
#
# 1. AVOIDS NEGATIVE BOUNDS:
#    - Using mean ± SD creates physically impossible negative values
#    - Example: PFT#7 leaf = 24.6 ± 29.1 → Min = -4.5 g C/m² (INVALID!)
#
# 2. LARGE STANDARD DEVIATIONS:
#    - Field measurements show high spatial variability
#    - PFT#10 fineroot: 382.1 ± 267.1 (SD = 70% of mean!)
#    - Using ±SD would create very wide acceptance ranges (115-649 g C/m²)
#    - Too permissive for model evaluation
#
# 3. CONSISTENT TREATMENT:
#    - ±20% provides uniform relative uncertainty across all outputs
#    - Standard approach in model-data comparison studies
#    - Allows meaningful multi-objective optimization
#
# 4. LITERATURE SUPPORT:
#    - Jackson et al. (1996): Root biomass estimates typically ±15-25% uncertainty
#    - Chapin et al. (2006): Arctic plant biomass measurement error ~20%
#    - Model evaluation studies commonly use ±20% threshold (e.g., Fisher et al. 2015)
#
# 5. CONSERVATIVE CRITERION:
#    - ±20% is MORE RESTRICTIVE than ±SD for most outputs
#    - Ensures model-data agreement is meaningful, not just within noise
#    - Appropriate for parameter optimization (avoids overfitting)
#
#
# ========================================================================
#
